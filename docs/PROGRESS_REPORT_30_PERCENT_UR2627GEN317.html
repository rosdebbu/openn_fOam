1. First-Principles Physical Modeling & Mathematical Equations

The platform discretizes continuous conservation laws for viscous, incompressible Newtonian fluid flows coupled with aerothermal buoyancy:

∇ · u = 0 [Mass Conservation / Incompressibility]
∂u∂t + (u · ∇)u = −1ρ∇p + ν∇2u + gβ(T − Tamb) [3D Momentum with Thermal Buoyancy]

where u = (u, v, w) represents the 3D velocity vector, p is kinematic scalar pressure (Pa), ν is kinematic viscosity (m2/s), ρ is fluid density (kg/m3), g = (0, 0, −9.81 m/s2) is gravity, and β = 1/Tamb is the volumetric thermal expansion coefficient driving buoyant convection updrafts.

∂T∂t + (u · ∇)T = α∇2T + ST [Thermal Energy Convection-Diffusion]
∂C∂t + ∇ · (C u) = 0 [Volume-of-Fluid (VOF) Phase Indicator]

Thermal diffusivity α = ν / Pr (where Prandtl number Pr ≈ 0.71 for air) controls conductive dissipation, and ST represents volumetric heat generation. The scalar indicator C ∈ [0, 1] captures fluid-air interface boundary dynamics with effective density ρeff = C ρfluid + (1 − C)ρair.
