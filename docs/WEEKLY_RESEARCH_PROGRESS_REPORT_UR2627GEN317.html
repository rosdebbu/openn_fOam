2. Physical Governing Equations & Numerical Scheme

The solver implements the continuous 3D incompressible Navier–Stokes equations coupled with Boussinesq thermal buoyancy and conservative scalar transport:

∇ · u = 0 [Continuity / Incompressibility]
∂u∂t + (u · ∇)u = −1ρ∇p + ν∇2u + gβ(T − Tamb) [Momentum with Thermal Buoyancy]

where u = (u, v, w) represents the 3D velocity vector, p is kinematic scalar pressure, ν is kinematic viscosity, ρ is fluid density, g = (0, 0, −9.81 m/s2) is gravitational acceleration, and β = 1/Tamb is the thermal expansion coefficient.

∂T∂t + (u · ∇)T = α∇2T + ST [Thermal Energy Convection-Diffusion]
∂C∂t + ∇ · (C u) = 0 [Volume-of-Fluid (VOF) Interface Advection]

Thermal diffusivity α = ν / Pr (Pr ≈ 0.71 for air) controls conductive dissipation. The fractional-step projection method separates the velocity update into an intermediate advection-diffusion prediction (u*) and an elliptic kinematic Pressure-Poisson divergence-free correction:

∇2p = ρΔt ∇ · u*   ⇒   un+1 = u* − Δtρ ∇p [Poisson Solve & Divergence-Free Projection]
