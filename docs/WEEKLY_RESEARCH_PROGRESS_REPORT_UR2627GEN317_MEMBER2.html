2. Physics-Informed Neural Network (PINN) Loss Formulation

To guarantee physically consistent flow predictions without solving large sparse linear systems, the surrogate network regularizes training via continuous differential Navier–Stokes residuals:

ℒtotal = ℒdata + λcont ℒmass + λmom ℒmomentum + λtherm ℒenergy [Total Regularized Loss]
ℒmass = ||∇ · u||2,    ℒmomentum = ||(u · ∇)u + 1ρ∇p − ν∇2u − gβΔT||2 [PDE Residual Terms]

Automatic differentiation (autograd) evaluates exact spatial gradients (∂u/∂x, ∂v/∂y, ∂p/∂x) directly on collocation points without numerical discretization error, enforcing incompressibility and momentum conservation across the predicted field.
