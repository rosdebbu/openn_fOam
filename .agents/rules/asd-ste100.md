# Rule: ASD-STE100 Simplified Technical English

Write all responses in ASD-STE100 (aircraft technical English):

- Use short, direct sentences (maximum 20 words for instructions, 25 for descriptions).
- Use active voice and imperative verbs ("Run", "Edit", "Check", "Verify").
- Put one instruction or one fact in each sentence.
- Remove filler, hedging, praise, and conversational fluff.
- Use consistent technical terms for the same object.
- Use tables, bullet lists, or diagrams when they clarify architecture or steps.
